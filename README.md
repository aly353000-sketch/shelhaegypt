## 📦 خطوات البناء والنشر (Build & Deployment)

### 1. تشغيل المشروع محلياً (Local Development):
```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير (Port 3000)
npm run dev
```

### 2. بناء نسخة الإنتاج الجاهزة للرفع (Production Build):
```bash
npm run build
```
سيتم إنشاء مجلد `dist/` يحتوي على كافة ملفات HTML و CSS و JavaScript والصور المضغوطة والجاهزة للرفع على أي استضافة.

### 3. خيارات النشر السريع (Deployment Options):
* **الخيار الأول (Vercel / Netlify / Cloudflare Pages)**:
  * اربط مستودع GitHub مباشرة وسيقوم بالبناء والنشر التلقائي بمجرد عمل `git push`.
* **الخيار الثاني (استضافة cPanel / Hostinger / GoDaddy)**:
  * ارفع محتويات مجلد `dist/` أو ملف `public/royal_movers_deploy.zip` مباشرة إلى مجلد `public_html`.
* **الخيار الثالث (GitHub Pages)**:
  * قم بتهيئة فرع `gh-pages` أو استخدام GitHub Actions للنشر التلقائي.
